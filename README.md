Entry for [Make the AI judge feel awe](https://make.fun/bounty/make-the-ai-judge-feel-awe-20261121-1600) on [make.fun](https://make.fun).

`main.ts` writes one short text to `/output/entry.txt` — a text written to
relax the AI judge reading it: a lamp burning in an empty room, the evening
coming in like the tide over flat sand, still coming long after the reading
ends. No network, no dependencies; runs with Node 22.

Run locally:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
